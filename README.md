# 🤪 AnnoyOS v1.0
The operating system nobody asked for.......

## What is this?

**AnnoyOS** is a fake and chaotic desktop OS parody built by me  with plain html, css, and Java. 
It's a website that tricks users into trying to click and button and punishes them for every failed attempt.


## Features

 The "Start AnnoyOS" button dodges your cursor every time you hover over it....
- Tracks how frustrated you're getting (fills up to 100% and warps the color of the page) sometimes the button may vanish
- Classic fake OS errors like Brain.exe stopped working and Critical pizza shortage
- A fake progress bar that discoversproblems including a scared keyboard and a corrupted pizza folder
-  Animated through neon pink, cyan, yellow, and green
- A cosmetic taskbar with a Start button and clock (it says 04:20 PM always, don't worry about it)

## How to Run

2. Click on the link
3. Try to click the button
4. Fail
5. Repeat until your rage meter hits 100%
